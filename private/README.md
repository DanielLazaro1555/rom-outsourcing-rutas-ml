# Carpeta privada

Esta carpeta agrupa documentos de apoyo, borradores y referencias internas del proyecto.
No forman parte del flujo principal de ejecucion de la aplicacion, pero sirven para
mantener contexto tecnico, academico y de redaccion.

## Contenido

| Archivo | Proposito |
| --- | --- |
| [Informe.md](./Informe.md) | Documento academico principal del proyecto y base conceptual de la propuesta. |
| [avance_tecnico_codex_2026-07-13.md](./avance_tecnico_codex_2026-07-13.md) | Resumen tecnico de lo implementado y de las decisiones tomadas en una revision anterior. |
| [informe_analysis.md](./informe_analysis.md) | Analisis comparativo entre el informe academico y el estado del codigo. |
| [podman_walkthrough.md](./podman_walkthrough.md) | Guia de ejecucion y verificacion del proyecto usando Podman. |
| [project_roadmap.md](./project_roadmap.md) | Hoja de ruta con actividades por fases para alinear el codigo con el informe. |
| [copia de env.txt](./copia%20de%20env.txt) | Copia local de variables de entorno usada durante pruebas. Revisar antes de compartir el repositorio si es publico. |

## Criterio de uso

- Mantener aqui documentos de referencia, analisis y planeacion.
- Evitar mezclar archivos temporales o salidas generadas automaticamente.
- Si un archivo deja de aportar contexto, moverlo a un archivo de historial o eliminarlo.

## Nota de seguridad

`copia de env.txt` contiene variables sensibles de entorno. Si el repositorio se publica,
verifica que no deban permanecer como datos locales antes de subir cambios.
